The tidymodels Workflow

This assignment uses the tidymodels framework for building predictive models. Here’s the general workflow:

1. Data splitting: Divide data into training and testing sets

  • initial_split() - Create the split
  • training() and testing() - Extract the sets

2. Recipe: Define preprocessing steps

  • recipe(outcome ~ predictors, data) - Specify the model formula
  • step_*() functions - Add preprocessing steps (e.g., step_dummy(), step_other())

3. Model specification: Define the model type

  • logistic_reg() - Specify logistic regression
  • set_engine() - Choose the computational engine

4. Workflow: Combine recipe and model

  • workflow() - Create workflow
  • add_recipe() and add_model() - Add components

5. Cross-validation: Assess model performance

  • vfold_cv() - Create folds
  • fit_resamples() - Fit model to each fold
  • collect_metrics() - Get performance metrics

6. Final fit and prediction: Fit to training, predict on testing

  • fit() - Train the final model
  • predict() - Make predictions
  • roc_curve() and roc_auc() - Evaluate predictions

  1. Describe how bootstrapping can be used to estimate the proportion of Americans who have been harassed by their superiors or co-workers at their job.

Bootstrapping could be used to estimate the proportion of Americans who have been harassed by their superiors or co-workers at their job by sampling the survey data with replacement multiple times.

Bootstrapping quantifies the uncertainty of the percentage of Americans harassed because it can be done multiple times and confidence intervals can be established to get a prediction of the actual percentage.

  1. Calculate a 95% bootstrap confidence interval for the proportion of Americans who have been harassed by their superiors or co-workers at their job. Interpret this interval in context of the data.

Hint: Use the infer package workflow: specify() %>% generate() %>% calculate() %>% get_confidence_interval()

library(infer)
set.seed(1245)
boot_ci <- gss16_harass5 %>%
specify(response = harass5, success = "Yes") %>%
generate(reps = 1000, type = "bootstrap") %>%
calculate(stat = "prop")
get_confidence_interval(boot_ci, level = 0.95)
## # A tibble: 1 × 2

Interpretation: We are 95% confident that the proportion of Americans who have been harassed by their superiors or co-workers at their job is in between 15.2% and 19.4%.

Common Errors and Troubleshooting

Data preparation errors:

  • Error: “Can’t subset columns that don’t exist” → Check variable names in select() - they’re case-sensitive
  • Recoded variable still has old levels → Make sure you saved changes back to the dataset with <-
  • Training/testing split doesn’t work → Check that you ran drop_na() before initial_split()

Recipe errors:

  • Error: “All columns selected for the step should be numeric” → Check that your outcome variable isn’t included in preprocessing steps (use -all_outcomes())
  • Error: “object not found” in recipe → Make sure all variables in the formula exist in your data
  • Recipe steps in wrong order → Dummy variables should typically be created last

Workflow errors:

  • Error: “No method for objects of class recipe” → Use add_recipe() not just the recipe name
  • Forgot to specify engine → Make sure you used set_engine("glm") in your model specification

Cross-validation errors:

  • Error: “object not found” → Set seed before creating folds; make sure you’re using gss16_train not gss16_advfront
  • Metrics are all NA → Check that your outcome variable has correct factor levels

Testing data errors:

  • ROC curve won’t plot → Make sure predictions include probability columns (use type = "prob")
  • Error: “truth should be a factor” → Your outcome variable needs to be a factor with matching levels in train and test

Bootstrap errors:

  • Error: “success level not found” → Check spelling of success level (e.g., “Yes” is case-sensitive)
  • Confidence interval seems wrong → Make sure you set a seed and used enough bootstrap resamples (1000+)
